# 옥상동물전 — 온라인 1:1 플레이 빌드

사용자가 제공한 원본 동물 사진 6종을 게임 에셋으로 사용하는 Node.js + Socket.IO 웹게임입니다.

## 바로 실행
1. Node.js 18+ 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. PC 브라우저에서 `http://localhost:3000`

같은 Wi‑Fi의 아이폰에서 플레이하려면 PC의 내부 IP를 확인한 뒤 `http://PC의IP:3000` 으로 접속합니다. 두 기기에서 각각 닉네임을 입력하고, 한쪽이 방을 만든 뒤 방 코드 또는 초대 링크를 상대에게 보냅니다.

## 현재 들어간 기능
- 실사 원본 사진 기반 6캐릭터: 크록냥 / 게이퍼 / 햄붕이 / 빅딕 / 오도냥 / 바주냥
- 방 생성 / 코드 참가 / 초대 링크
- 온라인 1:1 실시간 턴 동기화
- 캐릭터 선택 후 자동 시작
- 각도 / 파워 / 바람 / 20초 턴
- 캐릭터별 3스킬, 3번 스킬 게임당 1회
- 캐릭터별 HP/공격 범위/공격력 차이
- 포물선 발사 / 폭발 / 반동 표현
- 옥상 지형 파괴 크레이터
- 큰 구멍 위 이동/피격 시 낙사 판정
- 3턴마다 보급상자
- 더블 / 화력 +30% / 참치캔 / 철갑 / 풍향반전
- 보급상자 근처로 이동 시 획득, 아이템 최대 2개
- 승패 처리 / 상대 연결 종료 처리

## 인터넷 친구와 플레이
코드는 온라인 멀티플레이 구조입니다. 외부 친구와 하려면 이 폴더를 Node.js를 지원하는 호스팅에 배포하고 `npm start`를 실행하면 됩니다. 서버는 `process.env.PORT`를 지원합니다.
